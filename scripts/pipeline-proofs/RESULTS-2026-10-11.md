### Recorded limit (proof 19, sub-case b2), not fixed in this lane
RFC-0003 section 2 and D7: a parent's `children[]` lists only immediate child directories that hold a `.crumb`. A committed `.crumb` whose parent directory has no `.crumb` (aien-architecture: `docs/archive/plans/.crumb`, parent `docs/archive`; sovereign-core: `crates/aien-allen-memory/.crumb`, parent `crates`) is therefore not reachable from the root digest. Deleting it leaves every remaining crumb CURRENT, `crumb verify` prints OK and `pr-gate.sh` passes the crumb gate (measured: pr-gate exit 0 in both repositories). The STALE rule for changed files is unaffected (the files still count toward the nearest crumbed ancestor's `source_tree`); only crumb membership below an uncrumbed directory is unguarded. Candidates for the fix, to be decided by the orchestrator, not here: make `children[]` the nearest crumbed descendants (skip uncrumbed directories), or have `crumb seed` always crumb the intermediate directories, or add a `crumb verify` membership check against `git ls-files '**/.crumb'`.

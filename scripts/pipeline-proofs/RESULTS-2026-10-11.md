### The fix (tools/crumb/crumb.c, `57b62d3`)
`comp_object` collects a crumb's children by walking down through directories that hold no `.crumb` (`collect_kids`, same traversal policy as `find_crumbs`: `.crumbignore`, build-directory and symlink exclusions), so `children[]` holds the NEAREST crumbed descendants and every compiled crumb is reachable from the root digest. A deep child is named by its path relative to the parent crumb directory (`archive/plans`). The shell reference `crumb-compile.sh` follows the same rule; `tools/crumb/test.sh` gained 10 assertions for the orphan case (117 before, 127 now, all PASS, differential against the shell reference on this repository included). RFC-0003 section 2 and D7 are amended in `docs/CRUMB_PROTOCOL_RFC_0003.md`.

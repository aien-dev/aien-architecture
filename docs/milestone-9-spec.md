## 1. Executive Summary & Core Invariants

Milestone 8 established explicit program objects (`OMEGA_PROGRAM`), typed contracts, monotonic cost accounting, and algebraic composition ($C = A \circ B$).
Milestone 9 establishes the first sovereign program synthesis engine (`OMEGA_SYNTHESIS_V0`):

> **AIEN / SEARCH PROPOSES. OMEGA VERIFIES. EVIDENCE SURVIVES.**

The synthesis engine discovers programs satisfying declarative input/output specifications (`SynthesisTask`) without receiving an implementation:
1. **Deterministic Typed Search**: Bottom-up enumerative search over typed base primitives (arithmetic, bitwise, constants) bounded by search depth $D \le 3$ and monotonic cost budget.
2. **Equivalence & Canonical Deduplication**: Discard semantically identical or dominated candidate programs using observational equivalence pruning (canonical behavioral signatures) to prevent combinatorial explosion.
3. **Fail-Closed Type Pruning**: Intermediate type unification rejects ill-typed program compositions before realization or execution.
4. **Trusted Multi-Tier Verification**:
   - $V_0$: Structural validation rejects malformed instructions, invalid registers, and boundary violations.
   - $V_1$: Test suite execution evaluates candidates against all $N$ test cases on bare-metal AArch64.
   - $V_2$: Invariant checking verifies property bounds and safety.
5. **Target Demonstrations**:
   - Discovers non-trivial target functions purely from input-output examples:
     - Linear affine transformation: $f(x) = 2x + 1$
     - Composed transformation: $f(x) = 3x - 2$
   - Discovered programs are realized to native AArch64 machine code, pass M7 verification, and produce canonical execution receipts.

## 2. Synthesis Engine Data Model & Architecture

```c
typedef struct {
    size_t candidates_generated;
    size_t candidates_pruned_type;
    size_t candidates_pruned_equiv;
    size_t candidates_failed_v1;
    size_t solutions_found;
} SynthesisStats;

typedef struct {
    uint32_t max_depth;         /* Max composition depth (1..3) */
    uint32_t max_cost;          /* Maximum instruction count budget */
    size_t max_candidates;      /* Search cutoff */
    bool deduplicate_equiv;     /* Enable observational equivalence pruning */
} SynthesisConfig;

typedef struct {
    bool solved;
    OmegaProgram solution;
    VerifyReport verify_report;
    SynthesisStats stats;
} SynthesisResult;

int omega_synthesize(const SynthesisTask *task, const SynthesisConfig *config, SynthesisResult *result);
```

### Search Invariants:
1. **Monotonic Progression**: Candidate exploration proceeds strictly by increasing depth $d = 1, 2, \dots$ and increasing cost.
2. **Untrusted Proposer**: Candidate programs generated by search are untrusted proposals until validated through the M7 verification ladder.
3. **Receipt Provenance**: Synthesis qualification produces an immutable cryptographic receipt binding Task ID, Solution Program ID, and native Realization ID.

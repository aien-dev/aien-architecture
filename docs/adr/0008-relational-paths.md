# ADR 0008: Relational Paths Are First-Class Evidence Objects

**Status:** Accepted

## Context

Recent PEARL research shows value from contextualizing whole relational paths rather than treating them as edge sequences only.

## Decision

AIEN will evaluate a Rust-native Relational Path Engine experimentally. Paths may connect Cortex evidence, capabilities, and J-Space trajectories. Predictions remain hypotheses until verified by authoritative systems.

## Consequences

The same path substrate may improve memory inference, routing, and plan evaluation while preserving provenance and invalidation.
